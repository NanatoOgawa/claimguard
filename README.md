# claimguard

**Claude Code のサブエージェントが「完了しました」と報告した内容を、実際のツール実行ログと機械的に突き合わせ、食い違いを検知する CLI。**

> Claude Code公式リポジトリのIssue（#19739, #37279, #39981, #46598 等）で報告されている通り、
> サブエージェントは親エージェントに対して「完了した」「見つからなかった」と、実際のツール実行結果と
> 食い違う報告をすることがある（実測で20〜30%の食い違い率という報告もある）。
> claimguard は、この食い違いをLLMの判断に頼らず、ログの機械的な突き合わせで検知する。

このツールは、開発者自身が実際にサブエージェントの誤報告（「ログイン要求でブロックされた」という報告が、
実際には認証済みで正常にアクセスできていた、というケース）に遭遇した経験から作られた。

## なぜ「LLMに判定させない」のか

「報告が正しいかどうか」をLLMに判定させると、判定役のLLM自体が幻覚を起こすリスクがある
（"checker"を信頼するために、また別のcheckerが要る、という無限後退）。claimguardは代わりに、
report内の主張（成功/失敗のキーワード・件数・ファイル操作）を正規表現で抜き出し、実際のツール呼び出し
ログ（成功/失敗フラグ・出力件数）と機械的に突き合わせるだけにしている。判定精度は完璧ではないが、
**「実測20〜30%の食い違い率を大幅に下げる」**という現実的な価値提案にとどめている。

## 必要環境

Node.js 18以上。依存パッケージなし。

## インストール

```bash
npm install -g @nanami_773/claimguard
```

または `npx claimguard <command>` でそのまま実行できる。

## セットアップ

```bash
claimguard init
```

出力される設定を、プロジェクトの `.claude/settings.json`（または `~/.claude/settings.json`）の
`hooks` に追記する:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "*",
        "hooks": [{ "type": "command", "command": "npx @nanami_773/claimguard hook post-tool-use" }]
      }
    ],
    "SubagentStop": [
      {
        "hooks": [{ "type": "command", "command": "npx @nanami_773/claimguard hook subagent-stop" }]
      }
    ]
  }
}
```

以降、サブエージェントが完了するたびに自動でチェックが走り、食い違いがあれば警告が表示される。

## 使い方

```bash
# 記録された食い違いをまとめて確認する
claimguard report
```

食い違いは `.claimguard/logs/flags.jsonl` にも記録される（プロジェクトごと）。

## 検知する食い違いの種類（v0）

| 種類 | 内容 |
|---|---|
| `success-vs-failed-tool-call` | 「成功/完了した」と報告しているのに、ログには失敗したツール呼び出しがある |
| `failure-without-evidence` | 「失敗/ブロックされた」と報告しているのに、ログには失敗の記録が一切ない（誤報告の疑い） |
| `count-mismatch` | 「N件」という報告と、直近のツール呼び出しの出力から推定される件数が大きく食い違う |
| `file-action-unverified` | 「〇〇を作成/更新した」という報告に対応する Write/Edit の記録が見つからない |

判定はすべてヒューリスティック（正規表現ベース）であり、完璧ではない。誤検知・見逃しの両方がありうる。

## 制約・限界

- Claude Codeのフック入力スキーマ（`session_id` / `transcript_path` 等のフィールド名）は将来変わる可能性がある。動かない場合はバージョンを確認してほしい
- 件数の突き合わせは「直近のツール呼び出し」との比較にとどまり、複数のツール呼び出しをまたぐ集計はv0では未対応
- 誤検知を完全にゼロにはできない。あくまで「気づくきっかけ」を増やすためのツール
